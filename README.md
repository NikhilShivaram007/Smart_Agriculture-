## 🌱 About the Project

**Smart Agriculture Management & Decision Support System** is a web-based agriculture platform developed using Python, Flask, SQLite, HTML, CSS, JavaScript and Machine Learning.

The system helps farmers manage crops, detect plant diseases, receive weather-based advice, manage farm activities, sell agricultural products and track farm expenses.

---

## 🎯 Main Objectives

* 🌾 Help farmers manage their crops efficiently
* 🧠 Provide crop recommendations using Machine Learning
* 🔬 Detect plant diseases from uploaded images
* 🌦️ Provide weather-based agricultural advice
* 🛒 Provide an online marketplace for farm products
* 💰 Manage farm expenses and income
* 📊 Provide farm profit and loss information
* 📅 Help farmers plan farming activities
* 🔔 Provide important farming alerts and notifications
* ♻️ Provide useful information about farm waste management

---

## 🚜 Main Modules

### 👤 User Management

* Registration
* Login
* Profile Management
* Edit Profile
* Logout

### 🌱 Crop Recommendation

The system provides crop recommendations based on:

* Nitrogen
* Phosphorus
* Potassium
* Temperature
* Humidity
* Soil pH
* Rainfall

### 🌿 Crop Management

Farmers can manage:

* Crop Name
* Crop Variety
* Area
* Planting Date
* Growth Stage
* Irrigation Status
* Soil Condition
* Pest Status
* Harvest Date
* Farming Notes

### 🔬 Plant Disease Detection

The system uses **Machine Learning** and **Deep Learning** for plant disease detection.

Farmers can upload a crop image and the system predicts the possible disease along with confidence information.

### 🌦️ Weather Advisory

Provides weather-related information and agricultural recommendations to help farmers plan farming activities.

### 🛒 Farm Marketplace

Farmers can add and manage agricultural products such as:

* Fruits
* Vegetables
* Grains
* Pulses
* Spices
* Dairy Products
* Other Farm Products

### 🛍️ Marketplace Cart

Users can:

* Add products to cart
* Update quantity
* Remove products
* View total amount
* Continue to checkout

### 💳 Checkout & Payment

The marketplace provides a checkout system for placing agricultural product orders and recording payment information.

### 💰 Expense Management

Farmers can record and manage their farm-related expenses.

### 📊 Farm Profit & Loss

The system helps farmers view income, expenses and profit/loss information.

### 📅 Farming Activity Planner

Farmers can organize and manage important farming activities and schedules.

### 🔔 Farming Alerts & Notifications

The system provides alerts and notifications related to farming activities.

### ♻️ Farm Waste Management

Provides information about useful ways to manage and reuse different types of farm waste.

### 🤖 AgriBot

AgriBot provides agriculture-related assistance and information to farmers.

## 🧠 Machine Learning

The system recommends suitable crops based on agricultural and environmental inputs.

### 🔬 Plant Disease Detection
